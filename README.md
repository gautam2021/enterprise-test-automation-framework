# Enterprise Test Automation Framework

A scalable Selenium Java Hybrid Automation Framework built using industry-standard design patterns and best practices.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Extent Reports
- Log4j2
- ThreadLocal WebDriver
- Page Object Model (POM)

## Features

- Thread-safe WebDriver Management
- Parallel Test Execution
- Explicit Wait Management
- Extent Reporting
- Log4j2 Logging
- TestNG Listeners
- Retry Analyzer
- Page Object Model

## Framework Structure

```text
base/
drivers/
listeners/
pages/
utilities/
tests/
```

## Run Tests

```bash
mvn clean test
```

## Reporting

